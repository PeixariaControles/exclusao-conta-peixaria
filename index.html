Solicitação de Exclusão de Dados

Se você deseja apagar os dados associados ao nosso aplicativo de gestão da peixaria, você pode fazer isso das seguintes formas:

1. Diretamente no Aplicativo (Autônomo)

Você mesmo pode limpar os seus dados cadastrados de forma independente:

  1. Abra o aplicativo e acesse o menu de Configurações.
  2. Procure e clique no botão em vermelho escrito "Apagar todo o aplicativo".
  3. Confirme a ação para que as informações e registros sejam limpos do sistema.

2. Suporte via E-mail

Caso encontre qualquer dificuldade ou queira solicitar a remoção dos dados diretamente com a nossa equipe, envie um e-mail para meuscontroles.dev@mail.com.

Tipos de Dados Excluídos

  • Nome e telefone de cadastro.
  • Informações comerciais e registros associados armazenados no aplicativo.
